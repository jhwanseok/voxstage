## Running it

- Postgres is Docker container `studio-db-1` on port 5433 (start Docker Desktop, then `docker start studio-db-1`).
- Dev servers: `python studio/dev.py` from the repository root. Backend 8710, frontend 5710 (`http://127.0.0.1:5710`).
  Restart both by hand after every backend change (stop the processes on those ports, run it again).
- Backend tests: `cd studio/backend && .venv/Scripts/python -m pytest -q` (about 3 to 5 minutes; uses the `studio_test` database,
  rebuilt by the migrations; do not run two runs at once).
- Frontend: `cd studio/frontend && npx tsc --noEmit && npx vitest run && npm run build`.
- **End to end:** `cd studio/frontend && npm run e2e`. It starts its own backend (`studio/e2e/serve_api.py`, port 8712, database
  `studio_e2e`, recreated on every run) and its own Vite (5712), exports to `studio/e2e/.out/exports/`, and drives the
  installed Google Chrome (no browser download). It never touches the development database. Takes about 2 minutes.

## Things to know

- **UI terms:** 속성 (a collected or stored thing), 항목 (a slot of a type or an API response item), 고정값 (a constant),
  값 only for typed constants. Easy Korean, no em dashes. Write scripts of 20+ lines to a file (heredocs with Korean break).
- The owner's development database holds draft bots `bank-ko`, `bank-en` and others. Do not use "저장소 파일로 다시 가져오기"
  (it replaces the draft) without asking; the bank API connections there are still in the old list form (R16b typed form not
  imported). A backup question was planned for the owner and has not been asked.
- Roles: `X-Studio-User: <email>` header, default is the local user with every role. `editor` edits, `publisher` publishes and
  rolls back, `admin` imports, creates and deletes bots. It is a guard against slips, not security.
- Only the newest 5 publications of a bot are kept (publication numbers are never reused).
- A rollback restores the bot's own files only; the domain's shared files stay as they are now (ST2 D1).
- Windows: the export directory is written with CRLF by text mode; compare after normalizing line ends (see the e2e test).
- The `hub-status` dashboard: `node tools/hub-status.js ask studio "<question>"` for questions to the owner, one at a time, with a
  recommendation and why. Reports go to the orchestrator session by SendMessage (status, work, outputs, what is needed next).
- `.serena/` is untracked and not ours.
